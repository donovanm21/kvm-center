# Code of Conduct

kvm-center follows the [Contributor Covenant][cc], version 2.1.

In short:

- Be respectful. Assume good faith.
- Critique code, not people.
- No harassment, discrimination, or personal attacks.
- Keep discussion on-topic and professional.

Unacceptable behaviour can be reported privately to the maintainers —
see [SECURITY.md](SECURITY.md) for contact channels (the same private
reporting path applies).

The full Contributor Covenant text is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

[cc]: https://www.contributor-covenant.org/
